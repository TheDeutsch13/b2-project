# Инструкция по запуску проекта GAMEGEAR (Windows / PowerShell)

## Клонирование (рядом лежат 2 репозитория)

```text
C:\Projects\
├── b2-project\
└── b2-common\
```

```powershell
cd C:\Projects
git clone https://github.com/TheDeutsch13/b2-project.git
git clone https://github.com/TheDeutsch13/b2-common.git
```

## Запуск

### 1) PostgreSQL + миграции

```powershell
cd C:\Projects\b2-project\services
docker compose up -d postgres
cd ..
.\scripts\migrate.ps1
```

### 2) Backend (2 терминала, `JWT_SECRET` одинаковый)

```powershell
# auth-service (8081)
cd C:\Projects\b2-project\services\auth-service
$env:JWT_SECRET="gamegear-dev-secret"
go run ./cmd/api
```

```powershell
# product-service (8082)
cd C:\Projects\b2-project\services\product-service
$env:JWT_SECRET="gamegear-dev-secret"
go run ./cmd/api
```

### 3) Frontend

```powershell
cd C:\Projects\b2-project\frontend
npm install
npm run dev
```

Открыть: http://localhost:5173

## Первый админ (после регистрации на сайте)

```powershell
cd C:\Projects\b2-project
.\scripts\grant-admin.ps1 -Email "admin@test.com"
```

После смены роли нужно **выйти и войти снова** (роль хранится в JWT).  
Админка: http://localhost:5173/admin

## Демо-товары (опционально)

```powershell
cd C:\Projects\b2-project\frontend
$env:SEED_EMAIL="admin@test.com"
$env:SEED_PASSWORD="ваш_пароль"
npm run seed:products
```
