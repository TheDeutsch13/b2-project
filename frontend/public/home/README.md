# Фон верхнего блока главной (hero)

Положите сюда файл **`hero.png`** — он на всю ширину экрана, текст «LEVEL UP YOUR SETUP» по центру поверх картинки.

Рекомендуемый размер: **1920 × 800 px** или шире (широкий баннер, `object-fit: cover`).

После замены файла достаточно обновить страницу (F5).

## Картинки категорий

См. папку **`categories/`** — файлы `mice.png`, `pads.png`, `keyboards.png`, `accessories.png`.
