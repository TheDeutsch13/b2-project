# Картинки категорий на главной

Положите сюда PNG/JPG/WebP с **точными именами**:

| Файл | Категория |
|------|-----------|
| `mice.png` | Мыши |
| `pads.png` | Коврики |
| `keyboards.png` | Клавиатуры |
| `accessories.png` | Аксессуары |

Рекомендуемый размер: **250 × 168 px** и больше (карточка ~280 px по высоте, картинка целиком, без обрезки).

После замены файла обновите страницу (F5). Пересборка не нужна.

Если файла нет — показывается запасная картинка из проекта.
