# Карусель на главной

Положите сюда пары файлов с **одинаковым номером**:

| Файл | Назначение |
|------|------------|
| `1.png` | Картинка слайда |
| `1.txt` | Текст: **1-я строка** — заголовок, **со 2-й** — описание |

Пример `1.txt` (только текст на слайде):

```
Новая коллекция мышей
Премиальные модели для FPS и MOBA
```

### Ссылка на товар при клике

В тот же файл `N.txt` добавьте **отдельной строкой** ID товара (из админки или URL `/product/123`):

```
Wallhack SP-005 Carnage Sora
product: 12
```

Другие варианты той же строки:

- `product_id: 12`
- `товар: 12`
- `/product/12`
- `link: /catalog` — любая другая внутренняя ссылка
- `link: https://example.com` — внешняя ссылка

Если строки с `product:` нет, слайд ведёт в каталог (`/catalog`).

**Как узнать ID:** откройте товар на сайте — в адресной строке будет `/product/12`, число `12` и пишите в `product: 12`.

Поддерживаются `1.png`, `2.png`, … (можно `.jpg` / `.webp`).

Нужны **оба** файла с одним номером: `1.png` **и** `1.txt`.

## Размер картинки для карусели (без «дыр» по бокам)

Блок карусели на сайте — **соотношение 2:1** (ширина в 2 раза больше высоты).

| Назначение | Размер (пиксели) |
|------------|------------------|
| Оптимально | **1320 × 660** |
| Для Retina / 4K | **2640 × 1320** |
| Минимум | **1200 × 600** |

Другие пропорции тоже подойдут, если соблюдать **2:1**, например: 1920×960, 1600×800, 2000×1000.

**Не подходят без полос:** квадрат 1000×1000, вертикаль 1080×1920 — по бокам или сверху/снизу останется пустое место (если показывать картинку целиком) или обрежется край (режим «на весь блок»).

Важный контент держите **по центру** и не слишком близко к краям — слева поверх идёт тёмный градиент с текстом из `N.txt`.

После добавления или изменения файлов:

```powershell
cd frontend
npm run sync:carousel
```

Или из корня проекта:

```powershell
node scripts/sync-carousel.mjs
```

Скрипт копирует картинки в `frontend/public/carousel/` и обновляет `frontend/src/data/carousel.generated.ts`.

При `npm run dev` синхронизация запускается автоматически, а при изменении файлов в `Carousel/` страница перезагружается сама.
